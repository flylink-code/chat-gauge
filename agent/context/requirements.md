# 需求摘要卡

## 事实源

- `docs/mvp.md`：0.1 范围、计量单位与验收条件。
- `README_zh.md`：面向用户的显示口径与支持范围。

## 当前结论

- 本机 Windows 原生 Chat，状态栏与右侧栏共用快照；不嵌入聊天输入框。各 Agent 的指标来源和验收状态以 `docs/multi-agent.md` 为准。
- 吞吐用 tok/s，上下文用 token 数；窗口上限未知不显示百分比。工作区多会话时列出全部对话标签，默认第一个，用户手动选择并按工作区记住，不猜焦点。

## 未决项

- 真机状态栏和面板仍需用户批准插件后验收；其他 Agent 不在 0.1 范围。
