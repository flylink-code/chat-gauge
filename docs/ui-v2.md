# 侧栏 UI v2 方案

原型：`prototype/panel-v2.html`（静态页，合成数据，亮/暗色，260/320/400 px）。

## 现状问题

| 现象 | 原因 |
| --- | --- |
| 矩形图所有块同一浅灰，分不出分类 | 原生 `Box` 的 `background` 只有 `muted`、`card` 和 5 个语义色调，无法给 7 个以上分类各配一种颜色。 |
| 块内没有名称，图下是纯文字列表 | 原生组件无法在块内放自适应标签，也没有悬停提示。 |
| 上下文数字、进度条、状态、缓存、速率各占一块，侧栏很长 | 每个指标独立成段，没有层级。 |
| 缺失指标显示大号 `—` 加一整句说明 | 缺失与有值的卡片外观相同。 |

## 方案

1. **面板改用 `ui: "html"`**（沙箱 iframe）。只有它能画按分类名固定配色、带标签与悬停提示的矩形图。Worker、权限和 `gauge.get / gauge.changed` 协议不变；面板收到的仍是数值快照，不含对话正文。
2. **上下文卡片**：标题行右侧放占用百分比，其下是 `105.2k / 400k token`、含压缩预留斜纹段的进度条、已用与剩余的精确数，最后一行写来源与时间。
3. **指标行**：缓存命中与速率并排，按宽度自动换行，数字不拆行。缺失的指标用虚线卡片，原因折叠在「为什么没有？」。
4. **构成图**：默认只画已占用分类，可切换到整个窗口（加入剩余与压缩预留）。面积按 token 数分配，小于约 900 px² 的块合并为灰色「其他」并在图下说明。图例逐项给出颜色、数量和占比，兼作无障碍的文字替代。剩余、压缩预留和按需加载收进折叠区，不并入已用总量。
5. **状态栏**：保持 `已用/窗口 · ≈速率`。占用 ≥ 75% 变琥珀色，≥ 90% 变红；无速率时只显示上下文。

## 约束与验证

- 配色已用 dataviz 校验器检查：亮色与暗色各 7 色均通过明度、色度与相邻色分离度；亮色下青、黄、粉对比度低于 3:1，因此块内保留数字和图例作为补偿。
- 分类颜色按名称固定，不随排名变化；未登记的名称使用灰色，不循环取色。
- 正式侧栏入口是 `src/panel.html`，不依赖原型的样例数据。`orca plugin shot local.chat-gauge --panel chat-gauge` 可抓取真实面板；HTML 面板不支持 `--act` 与 `--scenario` 回放。
- 重新声明 `ui: "html"` 会改变面板贡献，可能触发重新授权。
