# 0002 · 多对话显示全部标签，手动选择，不自动跟随焦点

## 上下文

一个工作区常有多个原生 Chat。自动跟随需要知道用户正在看哪一个，但 Orca 1.4.274 没有给插件实时焦点接口；插件只能读本地保存状态，而点击标签后的保存状态可能几分钟不更新，会漏掉切换（实测见 `agent/context/archive/chat-focus-follow.md`）。

## 决策

面板顶部列出工作区的全部 Chat 标签，默认选中名册里的第一个，状态栏显示所选对话。用户点击标签即切换，选择按工作区记住；所选对话从名册消失才回到第一个。不读取、不推测焦点；不按生成状态或更新时间挑选。

## 后果

用户多一次点击，但显示永远与所选标签一致，不会把旧对话标成“当前”。`src/chat-focus.ts` 保留但 worker 不再调用，待 Orca 提供可核对的实时焦点后，再恢复为“默认跟随、可手动固定”。
